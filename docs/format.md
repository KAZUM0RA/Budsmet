# Формат заповненого кошторису

Вивантаження (XLSX / PDF / HTML) повторює структуру вхідної відомості обсягів робіт
і додає цінові колонки.

| # | Колонка | Опис |
|---|---|---|
| 1 | № п/п | наскрізна нумерація позицій по всьому об'єкту |
| 2 | Найменування робіт та витрат | назва з відомості (або обрана з довідника) |
| 3 | Одиниця виміру | канонізована: `кв.м` → `м2`, `к-т` → `компл` |
| 4 | Кількість | обсяг із відомості або введений вручну |
| 5–8 | Ціна за одиницю, грн | роботи · матеріали · машини · всього |
| 9–12 | Вартість, грн | роботи · матеріали · машини · всього |
| 13 | Джерело ціни | історія · інтернет · довідник · вручну |

Ієрархія рядків зберігається:

```
Локальний кошторис 02-01-01_П-АБ.АР · Загальнобудівельні роботи   ← підсумок кошторису
  Розділ 1. Демонтажні роботи                                     ← підсумок розділу
    1  Демонтаж дверних коробок …            шт     8   237,50   1 900,00
    …
  Разом по розділу
Разом по кошторису
```

Наприкінці — блок нарахувань: прямі витрати (з розшифровкою на роботи/матеріали/
машини), ЗВВ, кошторисний прибуток, адміністративні витрати, ризики, ПДВ і
загальна кошторисна вартість, а також рядки для підписів «Склав» / «Перевірив».
