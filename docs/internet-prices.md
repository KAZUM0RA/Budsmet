# Аналіз цін в інтернеті

Типово застосунок рахує кошториси офлайн — з вашої історії та вбудованого
довідника. Цей режим додає ще одне джерело: пошук ринкових цін по місту об'єкта.

Він **не замінює** довідник, а доповнює його там, де довідник мовчить.

---

## Спершу — скільки це коштує

Пошукові сервіси рахують кожен запит. Застосунок робить **один запит на одну
роботу** (не на позицію: однакові роботи в різних розділах беруться з кешу), а
відповідь зберігає на 14 днів.

Заміряно на реальному кошторисі зі 129 позицій:

| Режим | Живих запитів | Скільки позицій отримали ціну з інтернету |
|---|---|---|
| «інтернет лише для невідомих робіт» | **0** | 0 — довідник знав усі роботи |
| «спершу інтернет», ліміт 40 | 40 | 25 |
| «спершу інтернет», без обмеження | **104** | 39 |

Безкоштовний тариф SerpAPI — 250 запитів **на місяць**. Тобто одне
перерахування у режимі «спершу інтернет» без обмеження з'їдає майже половину
місячної норми. Тому:

- типовий ліміт — **40 живих запитів на одне перерахування** (решта позицій
  спокійно береться з довідника), змінюється через `BUDSMET_WEB_MAX_QUERIES`;
- рекомендований режим — **«інтернет лише для невідомих робіт»**.

Зверніть увагу і на віддачу: зі 104 запитів придатну ціну дали 39. Решта
сніпетів або не містить цін, або містить їх в інших одиницях виміру, і такі
відповіді відкидаються. Це нормально — інтернет тут підказка, а не істина.

## Який сервіс обрати

Стан на серпень 2026:

| Сервіс | Безкоштовно | Картка | Придатність |
|---|---|---|---|
| **SerpAPI** | 250 запитів/міс | **не потрібна** | ✅ єдиний реально доступний варіант |
| Brave Search API | безкоштовний тариф скасовано у лютому 2026, тепер $5 кредитів | потрібна, ліміту витрат немає | ⚠️ ризиковано |
| Google Custom Search | 100 запитів/добу | — | ❌ закрито для нових користувачів, вимикається 01.01.2027 |
| Власний ендпоінт | залежить від вас | — | для свого прайс-агрегатора |

Далі — про SerpAPI, бо решта варіантів або платні, або недоступні.

## Крок 1. Отримати ключ

1. Зареєструйтесь на <https://serpapi.com/users/sign_up> — картка не потрібна.
2. Підтвердьте пошту.
3. Скопіюйте ключ зі сторінки <https://serpapi.com/manage-api-key>.

## Крок 2. Увімкнути

### На сервері

```bash
sudo nano /etc/budsmet.env
```

Впишіть дві змінні:

```
BUDSMET_PRICE_PROVIDER=serpapi
SERPAPI_KEY=ваш_ключ
```

Збережіть (`Ctrl+O`, `Enter`, `Ctrl+X`) і перезапустіть застосунок:

```bash
sudo systemctl restart budsmet
```

### На своєму комп'ютері

```bash
export BUDSMET_PRICE_PROVIDER=serpapi
export SERPAPI_KEY=ваш_ключ
./run.sh
```

## Крок 3. Перевірити, що працює

**У застосунку:** унизу лівої колонки напис має змінитись з «Інтернет-ціни
вимкнено» на «Інтернет-ціни: serpapi».

**Точніше — запитом однієї роботи** (підставте свій домен і логін):

```bash
curl -u shef:ВАШ_ПАРОЛЬ "https://ваш.домен/api/price?name=Утеплення+фасаду&unit=м2&city=Полтава&strategy=web_first"
```

У відповіді дивіться на поле `source`:

- `"web"` — усе працює, ціна з інтернету;
- `"catalog"` — до інтернету не дійшло: або ключ не підхопився, або пошук не
  дав придатних цін. Перевірте `details` — там буде назва провайдера і
  зразки знайдених цін;
- поле `skipped` з текстом «вичерпано ліміт запитів» — спрацював запобіжник.

## Крок 4. Обрати режим у кошторисі

У рядку налаштувань об'єкта, поле **«Джерело цін»**:

- **«Історія, довідник, а інтернет — лише для невідомих робіт»** — рекомендую.
  Мережа задіюється тільки там, де ні ваша історія, ні довідник роботи не
  знають. Найощадніше і найточніше: свої ціни завжди достовірніші за знайдені
  в мережі.
- **«Спершу історія, потім інтернет, потім довідник»** — коли хочете, щоб
  ринок перебивав довідник.
- **«Спершу інтернет»** — для разової звірки з ринком. Пам'ятайте про ліміт.
- **«Тільки довідник»** — мережа не використовується взагалі.

Після перерахунку в рядку статистики видно, скільки позицій оцінено з кожного
джерела, а біля кожної позиції в таблиці стоїть позначка «інтернет».

## Налаштування

| Змінна | Типово | Призначення |
|---|---|---|
| `BUDSMET_PRICE_PROVIDER` | `off` | `serpapi`, `brave`, `google`, `custom`, `off` |
| `SERPAPI_KEY` | — | ключ SerpAPI |
| `BRAVE_API_KEY` | — | ключ Brave |
| `GOOGLE_CSE_KEY`, `GOOGLE_CSE_CX` | — | ключ і ідентифікатор Google Custom Search |
| `BUDSMET_PRICE_ENDPOINT` | — | свій ендпоінт для провайдера `custom` |
| `BUDSMET_WEB_MAX_QUERIES` | `40` | ліміт живих запитів на одне перерахування; `0` — без обмеження |
| `BUDSMET_WEB_CACHE_DAYS` | `14` | скільки днів зберігати знайдену ціну |
| `BUDSMET_WEB_TIMEOUT` | `12` | таймаут запиту, секунд |

## Свій ендпоінт

Якщо у вас є доступ до власного джерела цін, підключіть його як `custom`:

```
BUDSMET_PRICE_PROVIDER=custom
BUDSMET_PRICE_ENDPOINT=https://ваш.сервіс/search
```

Застосунок звертається за `GET ?q=<запит>` і очікує:

```json
{"results": [{"title": "...", "snippet": "...ціна 450 грн/м2...", "url": "..."}]}
```

Ціни видобуваються з тексту `snippet` і `title` тим самим розбором, що й для
пошукових систем.

## Як саме визначається ціна

1. Формується запит виду `<назва роботи> ціна <місто> грн за <одиниця>`.
2. З заголовків і сніпетів результатів видобуваються суми в гривнях
   (`450 грн/м2`, `від 1 200 грн за м.кв`, `300-400 грн/шт` → береться середина).
3. **Ціни в інших одиницях виміру відкидаються** — якщо шукали за м², ціна за
   погонний метр не потрапить у розрахунок.
4. Знайдене ділиться на роботи й матеріали за словами-маркерами: «робота»,
   «монтаж», «послуги», «під ключ» проти «купити», «доставка», «в наявності».
5. Береться **медіана**, а не середнє, з відкиданням крайніх 20% — щоб один
   випадковий нуль у сніпеті не зіпсував розцінку.

Через це до ціни з інтернету варто ставитись як до орієнтира: вона зібрана з
рекламних оголошень, а не з ваших домовленостей із бригадами. Найточніший
результат дає ваша ж історія — тому після кожного погодженого кошторису
натискайте «В історію».
