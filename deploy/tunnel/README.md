# Доступ до застосунку через інтернет без сервера

Варіант без хмари, реєстрацій і картки: застосунок працює на вашому робочому
комп'ютері, а Cloudflare Tunnel робить його доступним за посиланням з будь-якої
точки. Дані нікуди не виїжджають — база лишається у вас на диску.

**Кому підходить:** ви працюєте з одного комп'ютера, іноді треба відкрити
кошторис з телефону або показати замовнику.

**Головне обмеження:** посилання працює, лише поки увімкнений ваш комп'ютер і
запущені обидві програми.

---

## Швидкий спосіб: посилання за одну хвилину

Нічого реєструвати не треба.

**1.** Встановіть `cloudflared`:

- **Windows:** завантажте `cloudflared-windows-amd64.exe` зі сторінки релізів
  <https://github.com/cloudflare/cloudflared/releases>, перейменуйте на
  `cloudflared.exe` і покладіть, скажімо, у `C:\cloudflared\`.
- **macOS:** `brew install cloudflared`
- **Linux:** `sudo apt install cloudflared` або пакет зі сторінки релізів.

**2.** Запустіть застосунок у першому вікні терміналу:

```bash
cd шлях/до/Budsmet
./run.sh
```

**3.** У другому вікні запустіть тунель:

```bash
cloudflared tunnel --url http://localhost:8000
```

Через кілька секунд у виводі з'явиться адреса виду
`https://якісь-слова.trycloudflare.com` — це і є ваше посилання.

> **Адреса змінюється при кожному запуску** і поки вона активна, застосунок
> відкритий усім, хто її знає — **пароля тут немає**. Для швидкого показу
> замовнику це прийнятно, для щоденної роботи — ні. Тоді робіть постійний
> тунель, як нижче.

## Постійний спосіб: своя адреса і пароль

Потрібен безкоштовний акаунт Cloudflare і домен, доданий до нього (підійде і
дешевий домен, і безкоштовний піддомен, делегований на Cloudflare).

1. Зареєструйтесь на <https://dash.cloudflare.com>, додайте свій домен.
2. **Zero Trust → Networks → Tunnels → Create a tunnel** → тип **Cloudflared**,
   назва `budsmet` → скопіюйте команду з токеном і виконайте її на своєму
   комп'ютері (вона встановить тунель як службу, яка стартує сама).
3. У розділі **Public Hostnames** додайте запис: піддомен `koshtorys`, ваш
   домен, Service — `HTTP`, `localhost:8000`.
4. **Захистіть входом:** **Zero Trust → Access → Applications → Add an
   application → Self-hosted**, вкажіть той самий піддомен і додайте політику
   **Allow → Emails** зі своєю поштою. Тепер Cloudflare питатиме код,
   надісланий на пошту, і сторонні всередину не потраплять. Безкоштовний тариф
   Zero Trust розрахований на 50 користувачів — вам вистачить з запасом.

Щоб застосунок теж стартував сам разом із комп'ютером:

- **Windows:** створіть ярлик на `run.sh` (або на команду
  `python -m uvicorn backend.main:app --port 8000`) у папці автозавантаження
  (`Win+R` → `shell:startup`).
- **macOS/Linux:** додайте запуск у автозавантаження середовища або створіть
  службу systemd за зразком [`deploy/vm/budsmet.service`](../vm/budsmet.service).

## Резервні копії

База лежить у файлі `budsmet.db` у каталозі застосунку. Копіюйте його **лише
коли застосунок зупинено** — інакше поруч лишається журнал `budsmet.db-wal`, і
копія самого лише `.db` виявиться порожньою. Найпростіше: зупинити застосунок
(`Ctrl+C`), скопіювати `budsmet.db` куди-небудь у хмарний диск, запустити знову.

Якщо застосунок має працювати безперервно, скористайтесь
[`deploy/vm/backup.sh`](../vm/backup.sh) — він робить копію коректно, не
зупиняючи роботу.
