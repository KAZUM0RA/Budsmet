# Розгортання Budsmet

Застосунок зберігає всі кошториси, історію цін і довідник в одному файлі SQLite.
Тому головна вимога до майданчика — **постійний диск**: без нього база
стиратиметься при кожному перезапуску. Саме на цьому відпадає більшість
безкоштовних тарифів.

## Куди можна поставити безкоштовно

| Майданчик | Постійний диск | Картка | Коли обирати |
|---|---|---|---|
| [**Oracle Cloud Always Free**](oracle/README.md) | так, 47 ГБ+ | для верифікації | 2 CPU / 12 ГБ — найпотужніша безкоштовна машина, якщо вдасться зареєструватись |
| [**Google Cloud Always Free**](gcp/README.md) | так, 30 ГБ | для верифікації | якщо Oracle відмовив: 1 ГБ пам'яті, лише регіони США |
| [**Свій комп'ютер + Cloudflare Tunnel**](tunnel/README.md) | так | не потрібна | без реєстрацій і картки; працює, поки увімкнений комп'ютер |
| Render, Koyeb, Fly.io, Hugging Face | **ні** | — | не підходять: база не переживе перезапуску |

Про безкоштовні тарифи PaaS варто знати окремо: у Render постійний диск лише
платний, у Koyeb безкоштовна машина **не може підключити** том (ті «2 ГБ SSD» —
тимчасові й зникають при перезапуску), у Fly.io безкоштовного тарифу більше
немає, а Docker-простори Hugging Face тепер вимагають платного акаунта.

## Що всередині

- [`vm/`](vm) — скрипти для будь-якої машини з Ubuntu 22.04/24.04:
  - `setup.sh` — повне встановлення: залежності, служба автозапуску, nginx зі
    входом за паролем, HTTPS від Let's Encrypt, шрифти для кирилиці в PDF,
    відкриття портів, щоденна резервна копія;
  - `update.sh` — оновлення до останньої версії (з копією бази перед тим);
  - `backup.sh` — резервна копія без зупинки застосунку;
  - `restore.sh` — відновлення з копії;
  - `budsmet.service`, `nginx-budsmet.conf` — шаблони конфігів.
- [`oracle/`](oracle/README.md), [`gcp/`](gcp/README.md) — покрокові інструкції
  для конкретної хмари (кроки в консолі відрізняються, скрипти однакові).
- [`tunnel/`](tunnel/README.md) — доступ через інтернет без сервера взагалі.

## Найкоротший шлях

На свіжій машині з Ubuntu, коли вона вже створена і порти 80/443 відкриті:

```bash
sudo apt-get update && sudo apt-get install -y git && \
sudo git clone --depth 1 --branch claude/web-app-cost-estimates-l1x9ef \
  https://github.com/KAZUM0RA/Budsmet.git /opt/budsmet/app && \
sudo /opt/budsmet/app/deploy/vm/setup.sh --domain ваш.домен --login ваш_логін
```

Скрипт наприкінці покаже адресу, логін і пароль. Пароль генерується випадковим
і показується **один раз** — збережіть його одразу.
